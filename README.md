# Real Role

Real Role gives a job posting a **Freshness Score** from 0 to 100: how likely it is to be a real, active opening. Every score shows the signals behind it. It also tracks your applications and reminds you when to follow up.

> Work in progress. The full README (architecture, setup, live link, demo video) lands at launch.

## Development

```bash
corepack enable   # or: npm i -g pnpm
pnpm install
pnpm check        # format, lint, typecheck, test
```
